# Controls

Two texts re-scored in every run so each report's numbers have a known reference point.

- `human-letter-1913.txt` — human. Opening of a letter by Elinore Pruitt Stewart, from *Letters of a Woman Homesteader* (1914),
  Project Gutenberg #16623, public domain. First-person, informal, written before any language model existed.
- `ai-marketing-paragraph.txt` — machine. A generic marketing paragraph generated by Claude Fable 5.1 (Anthropic) in October 2026,
  unedited.
