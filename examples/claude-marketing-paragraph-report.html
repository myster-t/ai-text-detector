Methods and limits

Binoculars (Hans et al., ICML 2024): the text's perplexity under a performer model divided by the cross-perplexity between an observer and the performer, which normalises for prompts and topics that make text predictable for reasons other than machine generation. This run uses the paper's reference models and thresholds. Input truncated to 512 tokens (272 scored here).

Perplexity and burstiness: how predictable the text is to a language model, and how much that varies sentence to sentence. Weak on short texts, formulaic genres and text dense with names or numbers.

Writing patterns and hidden characters: deterministic checks that need no model.

No detector proves authorship. Edited machine text can pass, and terse or formulaic human writing can be flagged. Read these numbers alongside drafts, sources and the writer's history.
